# Pick Perfect

Pick Perfect is a full-featured eCommerce platform designed to help users find the ideal gift for any occasion and recipient. Built with Django and PostgreSQL, the platform integrates secure payments via Stripe, scalable storage with Amazon S3, and is deployed on Heroku for reliability. It offers complete eCommerce functionality, enhanced by an AI-powered recommendation agent that assists users in selecting thoughtful gifts based on their needs—creating a smart and personalized gift-shopping experience.

## User Experience (UX)

### Initial Discussion

The Pick Perfect project aims to solve the common problem of selecting the perfect gift for different occasions and individuals. Choosing a meaningful and appropriate gift can often be confusing and time-consuming, especially with the wide variety of options available online. This project introduces a smart eCommerce platform that not only provides a complete online shopping experience but also assists users in making better decisions. By integrating an AI-powered recommendation system, users can receive personalized gift suggestions based on their preferences, occasion, and recipient. Built using Django and PostgreSQL, and supported by technologies like Stripe for secure payments, Amazon S3 for storage, and Heroku for deployment, Pick Perfect delivers a reliable, scalable, and user-friendly solution for modern gift shopping.


### User Goals

Easily find suitable gifts for different occasions and recipients
Save time by quickly browsing and filtering products
Get personalized gift recommendations using the AI agent
Make secure and smooth online payments
View detailed product information before purchasing
Add products to cart and manage orders efficiently
Track orders and receive updates on delivery
Access the platform anytime with a reliable and fast system
Reduce confusion in gift selection with smart suggestions
Enjoy a simple, user-friendly shopping experience

🧳 User Stories

### As a traveler,
I want to search for flights by destination, dates, and price range,
so that I can easily find travel options that fit my budget and schedule.

### As a user,
I want to browse products by category so that I can easily find gifts for specific occasions.
I want to search for products so that I can quickly find a specific item.
I want to view detailed product information so that I can make an informed purchase decision.
I want to add items to my cart so that I can purchase multiple products at once.
I want to securely complete payments using Stripe so that my transactions are safe.
I want to receive personalized gift recommendations from the AI agent so that I can choose the perfect gift.
I want to filter products based on price, occasion, and recipient so that I can narrow down my choices.
I want to create and manage my account so that I can track my orders and save my preferences.
I want to track my order status so that I know when my gift will arrive.
I want to store and access product images reliably so that I can clearly see what I’m buying.


### As a Admin,
I want to manage products (add, update, delete) so that the store stays up to date.
I want to manage orders so that I can ensure smooth delivery and customer satisfaction.
I want to monitor payments so that I can verify successful transactions.
I want to analyze user activity so that I can improve recommendations and sales.

## Main Features

- Full-featured eCommerce platform with product browsing and purchasing  
- AI-powered gift recommendation agent for personalized suggestions  
- Search and filter products by category, price, occasion, and recipient  
- User authentication (signup, login, logout) and profile management  
- Shopping cart and checkout system  
- Secure payment integration using Stripe  
- Order management and order tracking  
- Product image storage using Amazon S3  
- Responsive and user-friendly interface  
- Admin panel for managing products, orders, and users  
- Scalable deployment on Heroku
